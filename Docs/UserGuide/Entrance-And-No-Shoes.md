# 玄関・土足禁止エリア

[ガイドへ戻る](Home.md)

## できること

入植者が建物へ出入りする際、プレイヤーが指定した玄関で履物の脱着を模した動作を行います。土足禁止エリアの内側では裸足の状態を管理します。**実際の装備アイテムを脱ぎ着する機能ではありません。**

## 設定の概要

1. 建築メニューのゾーン関連操作で**玄関**を指定します。
2. 玄関に辺で接する室内側に**土足禁止エリア**を指定します。
3. ポーンが玄関を通過したときの脱着・進捗表示を確認します。

斜め接触だけでは玄関は有効になりません。玄関の隣に土足禁止セルがない場合、履物の脱着は発生しません。

## 通常通行と緊急時

通常移動では玄関で履物の脱着に時間を使います。徴兵中や救助などの緊急ジョブでは、脱着によって移動が止まらない設計です。

代表シナリオの自動実ゲーム検証ではRimWorld 1.6・1.7の救助搬送に成功しています。あらゆる緊急ジョブや他Modとの併用を保証するものではありません。

## 実プレイで確認したいこと

出入口が複数ある間取り、ゾーンを後から編集した場合、通常の食事・睡眠への移行、長期間のセーブ継続などは、各プレイヤーの環境で確認する必要があります。
