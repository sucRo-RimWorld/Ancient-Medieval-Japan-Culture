# 履物の脱ぎ履き場所・土足禁止エリア

[ガイドへ戻る](Home.md)

## できること

土足で使う空間と、履物を脱いで使う板間・座敷などの境界で、入植者が履物の脱ぎ履きを**模した動作**を行います。通過には通常約90ゲームtickの停止と進捗表示があり、ポーンごとの裸足／土足の擬似状態を保存します。**本物の靴や防具の装備を変更するわけではありません。**

現行の機能は玄関という建物、専用家具、土間の床材、床の段差を必要としません。土間や上がり口だけでなく、既存の床・区域と重ねて任意の境界を指定できます。

## 設定方法

1. ゾーン関連メニューから**履物の脱ぎ履き場所**を指定します。
2. そのセル群と**上下左右の辺で接する**ように、屋内側などへ**土足禁止エリア**を指定します。
3. 入植者が境界を通過するとき、脱ぐ／履く動作と進捗バーを確認します。

斜めの接触、間に一マス以上の空白がある配置、脱ぎ履き場所を通らない侵入では切替が行われません。複数の出入口を指定できますが、屋根・ドア・部屋判定から自動的に境界を推測しません。

## 清掃用ドアマットModとの違い

[Door Mat](https://steamcommunity.com/sharedfiles/filedetails/?id=1505423207) と [Doormats](https://steamcommunity.com/sharedfiles/filedetails/?id=3239838811) は、建設したマットを通過するポーンの持ち運ぶ汚れを処理し、室内を清潔に保つための**家具・清掃Mod**です。Cultureはマットの設置や汚れ全般の自動洗浄ではなく、**生活空間の境界と履物習慣**を表現します。

| | ドアマットMod | Culture |
| --- | --- | --- |
| 設定 | マット家具を建設 | 脱ぎ履き地点と土足禁止範囲を指定 |
| 作用 | 通過時の汚れ処理 | 境界での擬似脱着、状態の保存、持ち込んだ土汚れの除去 |
| 効果対象 | 各Modの汚れ処理対象 | Cultureでは履物切替時の `Filth_Dirt` のみ |
| 履物の状態 | 脱着状態を管理しない | ポーン別の裸足／土足状態を保持 |

**両者とも持ち込み汚れを減らすため、清掃上の効果には重複があります。** Cultureがドアマットより清潔になるとは主張しません。両Modを併用した際の効果の加算や完全互換は未検証です。マットを置けば履物の脱着が起きるわけでも、土足禁止区域だけで脱着が起きるわけでもありません。

## 対象と制限

通常移動では脱ぎ履きの停止がありますが、徴兵・代表的な緊急救助などでは停止を省略し、元の移動Jobを維持します。靴を脱ぐときにはポーンが保持する**土汚れのみ**を除去し、血液・嘔吐物・作業汚れなどは原則そのままです。裸足ならどんな地面を歩いても汚れなくなる機能ではありません。救助搬送の限定実ゲーム確認はありますが、すべての緊急Jobや第三者Modとの併用を保証しません。

## 名称について

「玄関」は中世には主に禅宗寺院などに関わる名称で、今日のように一般住宅の出入口全般を指す用法は後世のものです。そのためUIでは建物の**玄関**を必須とするような名称を避け、歴史的な土間・上がり口での生活習慣を現行ゲームの境界指定として抽象化しています。参照：[大谷大学「玄関」](https://www.otani.ac.jp/yomu_page/b_yougo/nab3mq000001wkkz.html)、[國學院大學「なぜ日本には玄関があり、敷居があるのですか？」](https://www.kokugakuin.ac.jp/article/11129)。

## 実プレイで確認する点

複数の出入口、ゾーン編集後の移動、食事・睡眠への移行、長期セーブ継続、各ドアマットModとの実際の併用については、現在の限定検証では網羅していません。
