# 機能の実装状況

[ガイドへ戻る](Home.md)

このページは2026-10-28時点のCulture本体の実装範囲・公開対象を示します。**製品実装と実ゲーム受け入れは別**に扱います。

| 機能 | 現状 |
| --- | --- |
| 玄関・土足禁止エリア | 製品に実装。通常通行、徴兵、代表的な救助などの限定実ゲーム検証あり。実プレイ確認は継続 |
| イス単独での食事 | 製品に実装。1.7の一部統合テストに未解決の停止あり |
| 共同寝所に関する心情調整 | C#・XML実装あり。各条件での全面的な受け入れは別 |
| 時代に合わない娯楽薬・戦闘薬などの供給制限 | Vanilla・MO向けXML/C#実装あり |
| 新規ポーンの初期薬物依存・耐性調整 | 製品C#実装あり |
| 豊かな食生活を期待する人物の玄米・雑穀への不満 | Grainsが有効な場合の条件付き製品実装。現在の更新済みDLLに含むが実ゲーム受け入れ前 |
| 筵・菰の多用途敷物 | **初回公開対象外・将来延期**。1.6 Vanillaの技術検証PoCのみ成功。専用ThingDef・画像・製品実装は未完成。初回公開の必須条件ではない |
| 自動収納する折り畳み寝具 | 旧案として保留。完成製品ではない |
| 背景・特性 | 別Mod [Backgrounds & Traits](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Backgrounds-and-Traits)の担当 |
| 祭礼・芸能 | 将来のCulture系列子Modで検討。本体には未実装、初回公開条件外 |

## 仕様の参照先

正式な実装仕様・ゲーム試験記録は[Culture設計書](../Design.md)、敷物の詳細は[多用途筵の設計](../Features/MultipurposeMat.md)が正本です。このガイドを仕様変更の決定場所にはしません。
