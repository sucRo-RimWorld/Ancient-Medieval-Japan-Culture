# イスと食事

[ガイドへ戻る](Home.md)

## 食卓がなくてもイスを使う

Vanillaでは食卓に接していないイスが食事に使われにくい場面があります。Cultureは、**食卓が使えないとき、座ることのできるイスを食事場所として選ぶ**処理を追加します。

- 食卓に接した適切な座席があれば、通常はそれを使います。
- 利用できる食卓席がなければ、別の座れるイスを探します。
- 適切なイスがなければ、通常の移動・食事動作に戻します。

新しい食卓やイスの家具画像を追加する機能ではなく、既存の座席の選び方を変える機能です。

## 制限

1.7では食事開始の統合テストに停止した履歴があり、原因が確定していません。現行DLLのすべての飲食状況について動作保証するものではありません。

## ほかの食事関連機能

- **食卓なしの食事心情:** 一部の心情調整XMLが存在します。
- **Grains連携の雑穀・玄米心情:** Grains導入時のみ、対象の背景や特性と食料の豊富さ等に応じた不満を判定する処理があります。今回の実ゲーム動作は未受け入れです。
- **筵・菰:** 就寝と食事を兼ねる敷物は開発予定です。現在のCultureには完成品の家具定義・画像がありません。
