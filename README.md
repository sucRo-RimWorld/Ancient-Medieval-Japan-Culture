# Ancient & Medieval Japan – Culture

RimWorld 1.6・1.7向けの生活文化調整Mod（開発版）。

**プレイヤー向けの説明・使い方:** [Cultureガイド](Docs/UserGuide/Home.md)

履物の脱ぎ履き場所・土足禁止エリア、イスを使う食事、実装状況を案内します。筵・食生活期待（Agriculture連携）は初回公開対象外です。詳細は[実装状況](Docs/UserGuide/Feature-Status.md)で区別しています。

- **Harmony:** 必須
- **Medieval Overhaul:** 任意
- **Backgrounds & Traits:** [背景・特性を担当する別Mod](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Backgrounds-and-Traits)
- **既存セーブ:** 途中導入は未検証。バックアップまたは新規ゲームを推奨。

開発仕様の正本は[Docs/Design.md](Docs/Design.md)です。

## Optional Culture-series modules (2026-10-20)

- Backgrounds & Traits / 背景と特性: [AMJ Backgrounds & Traits](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Backgrounds-and-Traits), separate historical backstories and traits.
- Tea / 茶・こがし湯: [Ancient-Medieval-Japan-Culture-Tea](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Culture-Tea), a separate non-drug daily-drinks Mod; no hard Culture requirement, game validation and original art still pending.

Do not duplicate these child Mods' product Defs inside Culture; neither child is a required dependency.
