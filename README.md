RimWorld 1.6・1.7向けの生活文化調整Mod（開発版）。

**プレイヤー向けの説明・使い方:** [Cultureガイド](Docs/UserGuide/Home.md)

玄関・土足禁止エリア、イスを使う食事、実装状況を案内します。未完成機能は[実装状況](Docs/UserGuide/Feature-Status.md)で区別しています。

- **Harmony:** 必須
- **Medieval Overhaul:** 任意
- **Culture – Characters:** [背景・特性を担当する別Mod](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Culture-Characters)
- **既存セーブ:** 途中導入は未検証。バックアップまたは新規ゲームを推奨。
